🎮 Game Overview

The California Counties Puzzle is an educational geography game where players drag and drop all 58 California counties onto their correct locations on an interactive map. The design system emphasizes clarity, playful learning, and visual feedback.

Core Design Principles

  • Educational First: Clear visual hierarchy helps players learn county locations
  • Color-Coded Regions: Seven distinct colors represent California's major regions
  • Responsive Feedback: Immediate visual and audio responses to player actions
  • Progressive Difficulty: Hint system adapts to player needs

Visual Feedback

  • Correct Placement: Green flash + success sound
  • Wrong Placement: Red shake animation + error sound
  • County Selection: Scale up + blue ring + pickup sound
  • Hint Usage: Target county pulses on map
  • Progress Update: Progress bar animates with shimmer effect

Drag & Drop Flow

  1. Click county in tray → County scales up, blue ring appears
  2. Drag county → Original fades, cursor shows dragging state
  3. Hover over map → Drop zones highlight
  4. Drop on correct spot → Success animation + sound
  5. Drop on wrong spot → Error feedback + county returns to tray

Progressive Hints

Level 1: "Look in the southern part of California" Level 2: "It's near Los Angeles, on the coast" Level 3: County target area pulses on the map
