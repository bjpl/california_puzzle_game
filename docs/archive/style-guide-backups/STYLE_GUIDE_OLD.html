📘 Introduction

This design system defines the visual language and interaction patterns for the California Counties Puzzle Game. Built with educational clarity, accessibility, and delightful user experience in mind.

Design Principles

🎯 Educational First

Every design choice serves learning. Clear information hierarchy, readable typography, and obvious interactions.

♿ Accessible by Default

WCAG 2.1 AA compliant. Keyboard navigation, screen reader support, and sufficient color contrast.

⚡ Performance Optimized

Smooth 60fps animations, efficient React patterns, and responsive across all devices.

🎨 Regionally Color-Coded

11 distinct regions with carefully chosen colors for cognitive mapping and visual differentiation.

🎨 Color System

Our color palette is built around California's 11 geographic regions, with each region having a distinct, accessible color. UI colors complement the region palette for actions, feedback, and navigation.

💻 Usage Guidelines

Best practices for implementing this design system in code.

CSS Custom Properties

Use CSS variables for consistency and theme flexibility

/* Import region colors */ import { getRegionHexColor } from './config/regionColors'; /* Use spacing scale */ padding: var(--space-6); gap: var(--space-4); /* Apply transitions */ transition: all var(--transition-base);

Component Patterns

Follow React/TypeScript patterns for maintainability

// Always type props interface CountyCardProps { county: CountyData; region: RegionName; onClick?: (countyId: string) => void; } // Use semantic color mapping const regionColor = getRegionHexColor(county.region);
