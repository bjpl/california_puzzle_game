🔧 Component API Reference

Complete prop documentation for all UI components.

Button Component API

Prop Type Default Description
variant 'primary' | 'secondary' | 'success' | 'danger' | 'warning' | 'ghost' | 'outline' 'primary' Visual style variant
size 'small' | 'medium' | 'large' 'medium' Button size preset
loading boolean false Show loading spinner
icon ReactNode undefined Icon on left side
iconRight ReactNode undefined Icon on right side
fullWidth boolean false Full width button
disabled boolean false Disabled state

Badge Component API

Prop Type Default Description
variant 'default' | 'info' | 'success' | 'warning' | 'error' | 'region' 'default' Visual variant
size 'xs' | 'small' | 'medium' | 'large' 'small' Badge size
region string undefined California region name for auto-coloring

Card Component API

Prop Type Default Description
variant 'default' | 'elevated' | 'bordered' 'default' Card style variant
padding 'none' | 'small' | 'medium' | 'large' 'medium' Inner padding
interactive boolean false Enable hover effects

Progress Component API

Prop Type Default Description
value number 0 Current progress value
max number 100 Maximum value
variant 'default' | 'gradient' | 'success' 'default' Visual style
size 'small' | 'medium' | 'large' 'medium' Progress bar height
animated boolean false Enable shimmer animation
showLabel boolean false Show percentage label

Typography Components API

Component Props Description
<Heading> level: 1-6, size: 'display' | 'title' | 'heading' | 'section' | 'subsection' | 'label' Heading elements with semantic HTML
<Text> size: 'xs' | 'sm' | 'base' | 'lg' | 'xl', weight: 'light' | 'normal' | 'medium' | 'semibold' | 'bold' Body text with size and weight variants
<Label> htmlFor: string, required: boolean Form label with accessibility support
<Code> inline: boolean, language: string Code display with syntax highlighting
