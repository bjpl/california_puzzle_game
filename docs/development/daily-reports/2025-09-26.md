## Technical Decisions Made

### 1. Animation Architecture

```
Decision: RequestAnimationFrame-based timeline
Rationale:
  ✓ Smooth 60fps animation
  ✓ Precise timing control
  ✓ Easy pause/resume
  ✓ Battery efficient

Implementation:
  useEffect(() => {
    let animationId
    const animate = () => {
      if (isPlaying) {
        updateYear()
        animationId = requestAnimationFrame(animate)
      }
    }
    animationId = requestAnimationFrame(animate)
    return () => cancelAnimationFrame(animationId)
  }, [isPlaying])
```

### 2. Auto-Pause Strategy

```
Decision: Pause after each founding + special 1850 pause
Rationale:
  ✓ Educational moments
  ✓ User-controlled pacing
  ✓ Highlight significant events
  ✓ Better information retention

Implementation (16:34):
  • Synchronous ref check (not async state)
  • Immediate animation stop
  • Delayed pause for dramatic effect
  • User continues via button
```

### 3. Performance Optimization

```
Decision: Direct DOM manipulation vs React state
Rationale:
  ✓ 60fps pan performance
  ✓ No unnecessary re-renders
  ✓ Smooth user experience
  ✓ Reduced CPU usage

Trade-off:
  ✓ Better performance
  ✗ Slightly less "React-like"
  ✓ Justified for animation
```
