## Technical Decisions Made

### 1. Feature-Based Organization

```
Decision: Group by feature instead of type
Rationale:
  ✓ Related code stays together
  ✓ Easier to understand features
  ✓ Better for large teams
  ✓ Scales with project growth

Structure:
  Before: components/ButtonComponent.tsx
  After:  components/ui/CaliforniaButton.tsx
```

### 2. Deprecation Strategy

```
Decision: Move to _deprecated/ folder, don't delete
Rationale:
  ✓ Preserve for reference
  ✓ Easy rollback if needed
  ✓ Clear what's deprecated
  ✓ Can remove later safely

Files Deprecated:
  • CaliforniaMap.tsx
  • CaliforniaMapDemo.tsx
  • CaliforniaMapReal.tsx
  • CaliforniaThemeDemo.tsx
  • SimpleMapTest.tsx
```

### 3. Index File Pattern

```
Decision: Add index.ts to each feature folder
Rationale:
  ✓ Clean imports
  ✓ Explicit public API
  ✓ Easy to refactor
  ✓ Hide implementation details

Example:
  import { CountyTray, CountyCard } from '@/components/county'
  // Instead of:
  import CountyTray from '@/components/county/CountyTray'
  import CountyCard from '@/components/county/CountyCard'
```
