## Technical Decisions Made

### 1. Dark Mode Color Strategy

```
Decision: Darker backgrounds, lighter borders/text
Rationale:
  ✓ Better contrast in dark theme
  ✓ Maintains visual hierarchy
  ✓ Meets WCAG AA standards
  ✓ Aesthetically pleasing

Color Relationships:
  Light Mode: Light bg + dark text
  Dark Mode:  Dark bg + light text
  Accent:     Always region color
```

### 2. Collision Detection Algorithm

```
Decision: closestCenter over default
Rationale:
  ✓ More intuitive for users
  ✓ Better for irregular shapes
  ✓ Handles overlapping counties
  ✓ Industry best practice

Alternative Considered:
  ❌ closestCorners: Less accurate
  ❌ rectIntersection: Too strict
  ✅ closestCenter: Optimal balance
```

### 3. Mobile Scrolling Approach

```
Decision: Native momentum scrolling
Rationale:
  ✓ Familiar UX on mobile
  ✓ No JavaScript overhead
  ✓ Better performance
  ✓ OS-native feel

Implementation:
  CSS: -webkit-overflow-scrolling
  Benefit: iOS-like momentum
  Trade-off: Vendor prefix needed
```
